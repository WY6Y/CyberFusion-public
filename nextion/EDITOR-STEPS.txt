CyberFusion — Nextion 2.4" Layout (NX3224T024_011)
==================================================

Base HMI (edit in Nextion Editor):
  nextion/hmi/CyberFusion_Simplex_24_base.HMI
  (rename on save if you prefer — e.g. CyberFusion_Simplex_24.HMI)

Regenerate PNG backgrounds (optional):
  cd nextion && python3 generate_backgrounds.py

EDITOR WORKFLOW
---------------
1. Open the base .HMI in Nextion Editor
2. Set your callsign on idle/status text fields
3. Set RX/TX frequency text to your simplex pair (e.g. 446.0000 MHz)
4. Set location label to your city
5. Save As your own .HMI, compile, upload to the display UART

After flashing, on the Pi:
  bash scripts/enable-nextion.sh

COLOR REFERENCE
---------------
Neon cyan headers, dark grid background — match dashboard/static/index.html
